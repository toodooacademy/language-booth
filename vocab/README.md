# Language Booth vocab (1005 concepts x 5 languages)

Generated by tools/build.py from src/*.txt. Do not edit the JSON files by hand. Edit src/ and rebuild.

## Files
- concepts.json: v2. Top-level keys: version, imageDir, imageExt, style, topics, tiers, count, concepts{id:{...}}, aliases, audio{dir,pattern}.
  - Each concept: id, label, en, emoji, topic, tier(1-5), pos, picturable, image("vocab/img/<id>.jpg"), promptSubject, order, enFreqRank, batch(b1/b2/b3), legacy.
- <lang>.json (vi, zh, ja, es, en): lang, name, speech, topics, tiers, pageSize, count, words[].
  - Each word: id("<lang>-<concept>"), concept, text, speak(TTS text), reading(pinyin/romaji), meaning(English; for en it is the Vietnamese gloss), topic, tier, pos, audio{he,she}, image, emoji, review(bool), legacy?
  - When an example exists: example_phrase, example_sentence, example_phrase_meaning, example_meaning, example_phrase_reading, example_sentence_reading, example_audio{he,she}.
  - ja adds: kana, example_phrase_kana, example_sentence_kana.
  - es adds: display (article + noun), gender (m/f), article.
  - en adds: gloss_vi.
- vocab-1000.csv: one row per concept, covering all languages, examples, and review_flags.
- review.json / review.csv: open items, currently native-speaker checks. review-resolved.json: dictionary flags that were checked by hand, with a note for each.
- audio/<lang>/<he|she>/<id>.mp3 and <id>-ex.mp3: mono, 24 kHz, 32 kbps, voices from ../voices.json.
- img/<id>.jpg: 256px JPEG. Note that `image` is always set, so fall back to `emoji` if the file 404s.

## Tools
- python3 tools/build.py: rebuild everything (~30 s) and verify against CC-CEDICT, JMdict, and Wiktionary in dicts/.
- nohup python3 tools/audio.py 6 > audio/runN.log &: resumable TTS. Skips files that are up to date (manifest signature). Progress is in audio/progress.json.
- python3 tools/images.py next 16 | status | slice SHEET 4 4 ids...: image queue. Progress is in img/progress.json.
- Example sources: src/ex1.txt (13 '|' fields: id|en_phrase|en_sentence|vi_phrase|vi_sentence|zh_phrase|zh_sentence|ja_phrase|ja_phrase_kana|ja_sentence|ja_sentence_kana|es_phrase|es_sentence). Add more as src/ex2.txt and so on.
